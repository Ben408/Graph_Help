Smart Help for Sage Intacct — distribution build 5 (v0.3.5)
================================================
Distribution: 5
Version: 0.3.5

This package is meant for people who are NOT on the developer's machine or LAN.
It loads the hosted Smart Help UI from the public web app. You do not need a
local database, OKF corpus, vector index, or LLM.

What you get
------------
- Side panel beside Sage Intacct (Ask / Guide / Context)
- Guide steps + field highlights on mapped screens (e.g. Close books)
- Concept cards, Peek, Skill Paths, Explore graph, What's New
- Links out to live Sage Intacct Help Center pages
- Home opens a wide overlay over Intacct

What you will NOT get (needs the developer's local engine)
----------------------------------------------------------
- Ask answers / cited procedures generated by the local LLM
- Anything that requires the knowledge engine on port 8765

Requirements
------------
- Google Chrome or Microsoft Edge
- A signed-in Sage Intacct session in that browser
- Internet access to:
    https://v0-concept-graph-demo.vercel.app

Install (unpacked)
------------------
1. Unzip this folder if you received a zip. Keep the folder intact
   (manifest.json must stay at the top level of the folder you load).
2. Open Chrome or Edge and go to:
     chrome://extensions
   or
     edge://extensions
3. Turn on Developer mode (top right).
4. Click "Load unpacked".
5. Select THIS folder (the one that contains manifest.json and readme.txt).
6. Pin "Smart Help for Sage Intacct" if you want quick access.

Use
---
1. Sign in to Sage Intacct in a normal tab.
2. Open Smart Help by either:
   - Clicking the extension action / toolbar icon, or
   - Clicking the green "Smart Help" button on the Intacct page, or
   - Choosing "Help on this page" (Smart Help intercepts it)
3. Try Close books under General Ledger for the best guided demo spine.
4. Use Context for concepts / Peek / Skill Path / Explore Relationships.
5. Use Home in the panel header for the wide overlay (Learn / Explore / Updates).

Settings (usually leave as-is)
------------------------------
Right-click the extension icon → Options (or Extension details → Extension options).

  UI base URL default:
    https://v0-concept-graph-demo.vercel.app

Only change this if you were given a different hosted URL that also serves /panel.

Privacy note
------------
The extension reads light page context from Intacct (title, screen label, module,
URL) to seed the panel. It does not send Intacct credentials. Copilot is not
modified.

Support
-------
If the side panel says the UI is not reachable, check your network and confirm
https://v0-concept-graph-demo.vercel.app opens in a normal browser tab.
